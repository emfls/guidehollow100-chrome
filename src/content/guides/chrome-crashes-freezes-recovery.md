크롬 창이 닫히거나 '응답 없음'이 반복되면 바로 재설치하기보다 메모리 부족, 확장 프로그램, 네트워크 오류를 구분하는 편이 빠릅니다. 즐겨찾기와 로그인 데이터는 건드리지 않는 순서로 정리했습니다.

## 이 글이 필요한 상황

탭 전체가 멈추거나 브라우저 자체가 꺼지는 상황을 다룹니다. 특정 사이트만 열리지 않는 문제와 구분해야 합니다.

## 먼저 확인할 순서

### 1. 문제의 범위를 분리합니다

동일한 주소를 다른 브라우저에서 열어 봅니다. 다른 브라우저도 실패하면 사이트 또는 네트워크 문제 가능성을 먼저 살피고, Chrome에서만 반복되면 브라우저 환경에 집중합니다.

### 2. 탭과 다른 앱의 부담을 줄입니다

작업 중인 문서부터 저장한 뒤 불필요한 탭과 무거운 앱을 닫습니다. 대용량 다운로드를 잠시 멈춰 메모리·디스크 부담이 줄었을 때 같은 증상이 나타나는지 비교합니다.

### 3. 크롬을 완전히 종료해 다시 실행합니다

창만 닫는 것과 프로세스 종료는 다릅니다. Windows 작업 관리자 또는 macOS 강제 종료에서 Chrome이 계속 실행 중인지 확인한 뒤 재시작합니다.

### 4. 확장 프로그램을 점검합니다

최근 설치·업데이트한 확장을 기억해 둡니다. `chrome://extensions`에서 의심되는 확장을 잠시 끄고 정상 여부를 비교합니다. 필요한 확장은 하나씩 다시 켜서 원인을 찾습니다.

### 5. 업데이트 상태를 확인합니다

우측 상단 메뉴 → 도움말 → Chrome 정보에서 업데이트 여부를 확인합니다. 변경 사항 적용을 위해 다시 시작할 때는 입력 중인 내용을 먼저 저장하세요.

### 6. 다른 프로필이나 게스트 환경에서 비교합니다

동기화 문제나 프로필 설정이 원인인지 판단하는 보조 검사입니다. 이 단계에서 기존 프로필·동기화 기록을 삭제하지 않습니다.

### 7. 여전히 반복되면 오류를 기록합니다

운영체제, Chrome 버전, 문제 발생 사이트, 오류 문구, 특정 확장 사용 여부를 메모합니다. 재설치는 동기화와 로컬 데이터 백업 여부를 확인한 뒤 검토합니다.

## 흔히 하는 실수와 주의사항

- '인터넷 연결 오류'와 '브라우저 강제 종료'는 진단 순서가 다릅니다.
- 쿠키·저장 비밀번호·프로필을 한꺼번에 지우면 원인 파악과 복구가 어려워질 수 있습니다.
- 회사·학교 관리 브라우저에서는 관리자 정책을 우회하지 않습니다.

## 점검을 마쳤는지 확인하기

확인한 내용은 날짜와 함께 간단히 기록하세요. 문제의 범위를 분리합니다 단계부터 변화가 있는지 비교하고, 해결되지 않았다면 마지막으로 확인한 조건을 메모한 뒤 제조사 또는 공식 기관의 안내를 참고합니다.

## 자주 묻는 질문

### Chrome만 종료되고 다른 브라우저는 괜찮아요

확장 프로그램, 브라우저 버전, 프로필 설정 순서로 비교하세요. 다른 브라우저까지 실패하면 네트워크·기기 문제를 먼저 살펴야 합니다.

### 재설치하면 북마크가 없어지나요

계정 동기화와 로컬 저장 상태에 따라 다릅니다. 재설치 전 북마크 내보내기와 동기화 상태 확인이 안전합니다.
